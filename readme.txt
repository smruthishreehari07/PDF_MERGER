📄 PDF Merger

A simple Python-based PDF Merger that allows users to combine multiple PDF files into a single PDF document using the PyPDF2 library.

🚀 Features
Merge multiple PDF files into one PDF.
User-friendly command-line interface.
Choose how many PDF files to merge.
Automatically generates a merged PDF file named merged-pdf.pdf.
Simple and lightweight Python script.

🛠️ Technologies Used
Python
PyPDF2

Enter y to continue.
Enter the number of PDF files you want to merge.
Enter the filenames of the PDF files one by one.
The program will merge the PDFs into:
text
merged-pdf.pdf
